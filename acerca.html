¿Qué es Reporte Fluvial?

Reporte Fluvial es una herramienta web gratuita y de código abierto creada para que cualquier persona pueda consultar, de forma rápida y clara, los niveles hidrométricos actuales de los principales puertos fluviales de Argentina.

El sitio fue diseñado para ser liviano, accesible desde cualquier celular y con actualización automática cada hora. No requiere registro, no instala nada y no tiene costo para el usuario.

Tecnologías utilizadas

Todo el proyecto está construido con tecnologías web estándar y gratuitas:

GitHub Pages GitHub Actions Node.js Chart.js PWA / Service Worker Open-Meteo API

La actualización automática de los datos se ejecuta mediante GitHub Actions (tarea programada cada hora), que ejecuta un script Node.js, obtiene los datos de las APIs públicas y los publica en el repositorio. El frontend es una Progressive Web App (PWA) instalable en dispositivos móviles.
