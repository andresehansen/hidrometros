     https://hidrografia.agpse.gob.ar/histdat/LAPLATA.dat
     Web: https://hidrografia.agpse.gob.ar/LaPlata/index.html
   - Fuente Secundaria / Fallback Activo (SHN - Alturas Horarias oficiales):
     Web: https://www.hidro.gov.ar/oceanografia/alturashorarias.asp
     API REST v1: https://www.hidro.gob.ar/api/v1/AlturasHorarias/LPLA/{YYYYMMDDHHmm}
   - Fuente de Respaldo / Backup (INA API a5 - Serie 3314 - Estación 1708 PVNyMM):
     https://alerta.ina.gob.ar/a5/obs/puntual/series/3314/observaciones
   - Pronóstico de Mareas (SHN):
     https://www.hidro.gov.ar/oceanografia/pronostico.asp
   - Clima y Viento (Open-Meteo):

2. IGUAZÚ
   - Fuente Primaria (AGPSE - Web / DAT crudo):
     https://hidrografia2.agpse.gob.ar/PuertoIguazu/index.html
     http://hidrografia2.agpse.gob.ar/histdat/PUERTO_IGUAZU.dat
   - Telemetría Automática INA (Serie 36964 - Estación 7277 RHN-SAT, cadencia 30 min):
     https://alerta.ina.gob.ar/a5/obs/puntual/series/36964/observaciones
     * PRIORIDAD POR DEFECTO: Brinda actualizaciones cada 30 minutos.
     * NOTA: Satura o se traba en 28.52m durante crecidas extremas al verse superada la cota física del sensor.
   - Escala Oficial Prefectura PNA (INA Serie 9 - tabla alturas_prefe id 20 / PNA Web):
     https://alerta.ina.gob.ar/a5/obs/puntual/series/9/observaciones
     https://contenidosweb.prefecturanaval.gob.ar/alturas/?page=historico&tiempo=7&id=20
     * REGLA DE ARBITRAJE: Si PNA informa una altura SUPERIOR y más actualizada (o si la telemetría automática está trabada/saturada), se asigna prioridad inmediata a la altura de Prefectura (Ground truth).
